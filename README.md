# Job Market Skill Analysis System

##  Project Overview
The Job Market Skill Analysis System analyzes job market data to explore in-demand skills, salary trends, job roles, and location-based employment opportunities.

##  Objectives
- Analyze job market data.
- Identify in-demand skills.
- Explore salary trends across job roles.
- Examine employment opportunities by location.
- Understand the relationship between skills and job market requirements.

##  Technologies Used
- Python
- Google Colab
- Pandas
- CSV dataset

##  Project Files
- `Job_Market_Data_Analysis(final).ipynb` – Jupyter notebook containing the project code and analysis.
- `job_market_skill_analysis_synthetic_2500.csv` – Synthetic dataset containing 2,500 records.
- `README.md` – Project documentation.

##  How to Run the Project
1. Open the notebook in this repository.
2. Click **Open in Colab** or download the notebook and upload it to Google Colab.
3. Download the CSV dataset from this repository.
4. Upload the CSV file to your Colab session.
5. Run the notebook cells in order.

##  Expected Analysis
The project is designed to explore:
- In-demand job skills.
- Salary patterns.
- Job role trends.
- Location-based job opportunities.

##  Dataset
The project uses a synthetic job market dataset containing 2,500 records. The dataset is intended for analysis and demonstration purposes.
